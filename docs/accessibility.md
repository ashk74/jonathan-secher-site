# Exigences d'accessibilité

Le site devra viser une conformité pragmatique aux bonnes pratiques WCAG 2.2 niveau AA.

- HTML sémantique et titres hiérarchisés.
- Navigation clavier visible et cohérente.
- Contrastes suffisants.
- Textes alternatifs pertinents pour les images informatives.
- Formulaires avec libellés et erreurs explicites.
- Respect de `prefers-reduced-motion`.
- Mise en page utilisable avec zoom et petits écrans.

Les contrôles seront réalisés sur le site effectivement construit ; cette liste n'est pas une déclaration de conformité.
