# Stratégie de contenu

## Audience envisagée
TPE/PME et professionnels de services recherchant une présence web claire et des usages IA concrets.

## Messages directeurs
- Expliquer les bénéfices métier avant les détails techniques.
- Montrer comment l'IA peut assister le professionnel tout en gardant son contrôle.
- Distinguer démonstration, hypothèse et réalisation client.
- Éviter les promesses de gains chiffrés non mesurées.

## Sections prévues
Accueil / présentation ; création de sites web ; « L'IA utile à votre métier » ; contact / demande de projet.

## Validation
Le contenu commercial, les prix, les délais, les coordonnées et les mentions juridiques devront être confirmés avant publication.
